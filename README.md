# NOOR TECHNOLOGIES

**Digital Solutions. Software. Technology Education.**

## About the Project

NOOR TECHNOLOGIES is a modern, responsive website for a technology company offering digital solutions, software development, and technology education.

The website is being developed with a mobile-first approach.

## Services

- Website Design & Development
- Custom Web Applications
- UI/UX Design
- Software & Digital Solutions
- IT Consulting & Support
- Tech Coaching & Training
- Website Maintenance

## Technology Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Linting:** ESLint
- **Package Manager:** npm

## Project Scope

- Frontend-only website
- Responsive design for mobile, tablet, and desktop
- No admin panel
- No backend
- No database

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Start Development Server

```bash
npm run dev
```

### 3. Open in Browser

Visit:

```text
http://localhost:3000
```

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Build production version |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |
